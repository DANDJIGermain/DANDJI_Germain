## Présentation
**Epitodo** a été mon premier projet web d'envergure. L'objectif était de concevoir une application complète de gestion de tâches (To-Do List) incluant un backend robuste, une base de données persistante et une interface utilisateur intuitive. Ce projet m'a permis de maîtriser les fondamentaux du développement Full-Stack et de la gestion d'utilisateurs.

## Technologies & Compétences
- **Backend (Node.js & Express)** : Création d'une API RESTful pour gérer les utilisateurs et les tâches.
- **Base de Données (MySQL/MariaDB)** : Conception du schéma relationnel, requêtes complexes et persistance des données.
- **Authentification (JWT)** : Mise en place d'un système sécurisé de connexion et d'inscription via des JSON Web Tokens.
- **Développement Frontend** : Création d'une interface dynamique permettant d'interagir en temps réel avec l'API (CRUD complet).
- **Architecture Logicielle** : Structuration du projet selon le modèle MVC (Modèle-Vue-Contrôleur) pour séparer proprement la logique métier de l'affichage.

*Projet réalisé durant ma 2ème année à Epitech (Tek2).*
